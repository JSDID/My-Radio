# Radio Channels

## Описание проекта

**Radio Channels** - это веб-приложение для прослушивания радиостанций через интернет. Проект представляет собой простой и удобный радиоприемник, который можно использовать на смартфонах и других устройствах.

## Основные возможности

- 🎵 **Прослушивание радиостанций** - доступ к множеству радиостанций через виджет MyTuner
- 📱 **Адаптивный дизайн** - оптимизирован для использования на мобильных устройствах
- 🎧 **Bluetooth поддержка** - возможность подключения наушников, автомобильной аудиосистемы или колонок через Bluetooth

## Технические характеристики

### Технологии
- **HTML5** - структура страницы
- **CSS3** - стилизация и адаптивный дизайн
- **JavaScript** - интерактивность (через виджет MyTuner)
- **MyTuner API** - интеграция с сервисом онлайн-радио

### Дизайн
- **Цветовая схема**: Темно-бирюзовый фон (#015a5a) с золотистыми акцентами (#f4a460)
- **Шрифты**: Montserrat для заголовков, Roboto для основного текста
- **Максимальная ширина**: 400px для оптимального отображения на мобильных устройствах

## Использование

1. Откройте `index.html` в веб-браузере
2. Выберите радиостанцию из списка
3. Нажмите кнопку воспроизведения
4. Подключите наушники или Bluetooth-устройство для лучшего звучания

## Особенности

- **Автономная работа**: Приложение работает без необходимости установки дополнительного ПО
- **Кроссплатформенность**: Доступно на любом устройстве с веб-браузером
- **Простота использования**: Интуитивно понятный интерфейс без лишних элементов
- **Оптимизация для мобильных**: Специально адаптировано для использования на смартфонах

## Разработка

Проект создан как простое веб-приложение без использования фреймворков, что обеспечивает быструю загрузку и минимальные требования к ресурсам.

## Лицензия

Проект распространяется свободно для личного использования.
